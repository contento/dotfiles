# Package manifest for bootstrap.sh — one row per tool, whitespace-separated.
#
#   name   Canonical name. Used in logs, and as the Homebrew formula name on Linux
#          (for `brew` entries and when a native install fails and falls back to brew).
#   tier   min  = installed by default
#          full = installed only with --all
#   brew   macOS (Homebrew). apt / dnf / yay: Ubuntu-Debian / Fedora / Arch.
#
# Values in the platform columns:
#   <pkg>      Install <pkg> with that platform's package manager. On Linux, a
#              failed native install falls back to `brew install <name>`.
#   cask:<pkg> brew cask (macOS column only)
#   brew       Install <name> from Homebrew instead of the native manager (Linux only)
#   fn:<name>  Call install_<name> from bootstrap.sh
#   -          Not installed on that platform
#
# Starship, git, curl, Python, nvm and TPM are handled in bootstrap.sh, not here.
